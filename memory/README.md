# Pamięć projektu

Ten folder to wspólna pamięć projektu dla ludzi i dla każdego asystenta AI (Claude, Gemini, ChatGPT, Copilot, Codex).
Asystent czyta te pliki przed pracą i dopisuje do nich to, czego się dowiedział.

## Pliki

| **Plik** | **Co zawiera** |
| --- | --- |
| [projekt.md](projekt.md) | Opis projektu, wyzwanie, źródła i linki |
| [pomysly.md](pomysly.md) | Pomysły z brainstormingu i otwarte pytania do nich |
| [decyzje.md](decyzje.md) | Podjęte decyzje oraz odrzucone pomysły wraz z powodami |
| [zadania.md](zadania.md) | Lista zadań do zrobienia |
| [firmy/](firmy/README.md) | Opisy przykładowych firm, dla których projekt ma działać (szablon w `firmy/_szablon.md`) |

## Zasady

- Pisz po polsku, krótko, w punktach.
- Jeden temat to jeden plik. Nowy plik dodawaj tylko wtedy, gdy temat nie pasuje do żadnego istniejącego, i dopisz go do tabeli powyżej.
- Przy decyzjach i zmianach stanu podawaj datę w formacie RRRR-MM-DD.
- Nie usuwaj cudzych wpisów. Pomysł, z którego rezygnujemy, przenieś do sekcji „Odrzucone” w `decyzje.md` i podaj powód.
- Gdy na otwarte pytanie z `pomysly.md` padnie odpowiedź, wpisz ją do `decyzje.md`, a samo pytanie skreśl (`~~pytanie~~`) i dodaj odnośnik do decyzji.
- Nie wpisuj haseł, tokenów ani danych osobowych.
